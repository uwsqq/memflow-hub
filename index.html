📤 Публиковать колоду

Нужен только аккаунт GitHub — колода появится в каталоге мгновенно.

  1. В MemFlow открой колоду → кнопка 🔗 Поделиться → скопируется ссылка.
  2. Вставь её сюда (или JSON вида {"name":…,"cards":[{"front":…,"back":…}]}).
  3. Проверь превью и нажми «Открыть GitHub с готовым issue» → опубликуй.
