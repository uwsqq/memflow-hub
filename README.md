# ☁️ MemFlow Hub — колоды сообщества

Каталог готовых колод для [MemFlow](https://uwsqq.github.io/memflow/) (spaced repetition, FSRS-17).
Публикация через GitHub issue — колода появляется в каталоге **мгновенно**, бот не нужен.

**🔗 Открыть: [uwsqq.github.io/memflow-hub](https://uwsqq.github.io/memflow-hub/)**

## Как это работает
Хаб читает два источника и склеивает их:
1. `catalog.json` + `decks/*.json` — сид-колоды из репозитория;
2. **issues с заголовком `[deck] …`** — колоды сообщества (публичный GitHub API, без токенов).

## Как скачать колоду
Кнопка **«➕ В MemFlow»** — колода автоматически добавится в приложение
(ссылка `#deck=…base64…`, работает даже без интернета после открытия).

## Как опубликовать колоду
1. Открой [хаб](https://uwsqq.github.io/memflow-hub/) → секция **«📤 Публиковать колоду»**.
2. Вставь ссылку `#deck=…` из кнопки «Поделиться» в MemFlow (или JSON `{"name":…,"cards":[…]}`).
3. Нажми «Открыть GitHub с готовым issue» → опубликуй — колода сразу в каталоге.

Ограничения: до 500 карточек, `front`/`back` ≤ 300 символов, картинки только по http(s).

## Добавить колоду в сиды (PR)
Положи `decks/<slug>.json` (`{"name","author","date","cards":[{"front","back","tags"?}]}`)
и добавь запись в `catalog.json`. В `scripts/publish.py` остаётся офлайн-валидатор формата.
